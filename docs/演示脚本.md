# AI 出海营销工坊 · 演示视频分镜脚本

- 时长目标：约 4 分钟（3–5 分钟区间内）
- 分辨率：1920×1080，浏览器全程访问 http://localhost:8080（Docker 部署环境）
- 解说：每幕字幕即解说词，可直接作为配音稿使用

## 分镜表

| 幕 | 时间 | 画面 | 操作 | 解说词（字幕） |
|---|---|---|---|---|
| 1 开场 | 0:00–0:15 | 首页整体界面 | 停留在资产中心页 | 这是「AI 出海营销工坊」，一个帮助跨境卖家用 AI 批量生成营销素材的全栈项目。前端 Vue3，后端 Express，已用 Docker Compose 一键部署在本地 8080 端口。 |
| 2 上传与识图 | 0:15–1:00 | 资产中心左侧上传面板 | 拖拽/点击上传商品图，填写商品名「原色帆布托特包」，点击上传并保存；卡片出现后点击「AI 一键识别」 | 上传一张商品图，系统做前端校验与后端多重校验后保存。点击「AI 一键识别」，识图大模型 qwen3-vl-plus 会自动提取外观特征、核心卖点和场景建议，结果直接展示在商品卡片上。 |
| 3 流式文案 | 1:00–2:00 | 文案工坊 | 选商品、语言 English、渠道 Amazon，点生成；观察打字机逐字输出；完成后切换 TikTok 渠道再生成一次，展示分镜表结构 | 进入文案工坊。同一份商品资料，Amazon 渠道生成结构化的五点描述，注意文字是 SSE 流式逐字输出的。切换到 TikTok 渠道再生成一次，模型自动改为 15 秒短视频分镜脚本。所有文案会做双层合规校验，禁止编造参数。 |
| 4 场景图 | 2:00–2:45 | 场景生图 | 选商品，选场景「城市通勤」，点生成；观察骨架屏，等待图片出现 | 场景生图：先用大模型把中文场景扩写成专业英文提示词，再调用万相模型异步生图。前端展示骨架屏占位，每 3 秒轮询任务状态，完成后主图直接展示在页面里，并保存到本地服务器。 |
| 5 导出与看板 | 2:45–3:30 | 资产中心 + 运营看板 | 回资产中心点「导出营销包」；切到运营看板查看统计 | 一键导出营销包：商品图、场景图、全渠道文案自动打包成 ZIP 下载。运营看板统计了每一次 AI 调用的 Token 消耗、成功率和失败明细，方便控制成本。 |
| 6 架构收尾 | 3:30–4:00 | 终端 docker ps + compose 文件 | 展示三容器运行状态与 docker-compose.yml | 最后看部署架构：MongoDB、后端、前端三个容器，Nginx 负责静态托管和反向代理，数据通过 Docker 卷持久化。整个项目从上传到素材产出，全链路由 AI 驱动。感谢观看。 |

## 录制注意事项

1. 录制前确认 `docker compose up -d` 三容器 Up、5173/3000 开发服务已关闭。
2. 浏览器窗口分辨率 1920×1080，缩放 100%，地址栏可见。
3. 每幕操作之间停顿 1–2 秒，方便后期剪辑。
4. 若重新配音，按「解说词」逐幕朗读即可，总字数约 550 字，语速 140 字/分钟。
