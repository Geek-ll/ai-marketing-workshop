# AI 出海营销工坊 · 演示视频分镜脚本

- 成片时长：4 分 44 秒（1920×1080 / 25fps / 含中文解说与字幕）
- 演示地址：http://localhost:8080（Docker Compose 三容器部署后的生产构建版本）
- 解说配音：edge-tts zh-CN-XiaoxiaoNeural，语速 −4%，逐幕合成后与画面对齐
- 录制方式：先定配音稿，再按每幕配音时长驱动浏览器操作与停留，画面、解说、字幕三者共用一条时间轴
- 结尾：停留在系统资产中心，不再跳转 GitHub 等外部页面

## 录制要点

1. 录制前 `docker compose up -d` 三容器处于 Up，5173 / 3000 开发服务已关闭，只留 8080 对外。
2. 演示数据保持干净：录制前清空商品与历史资产，从空列表开始上传，链路更完整。
3. 每一幕的停留时长由该幕配音时长决定，操作做完后停在本幕画面直到配音结束，保证「看到的」和「听到的」一致。
4. 等待生图、等待流式输出等环节不做剪辑加速，用骨架屏和打字机画面真实呈现，同时在解说里说明机制。
5. 画面中不出现 `.env`、控制台 Key 页面；结尾不跳转外部站点。
